## 7. Not distributed — host dependencies

The following are required on the user's machine but are **not** part of StemForge's bundle. Their licences are between the user and their operating system or platform vendor:

- **Linux:** GTK 3, WebKitGTK 4.1 (+ GIR typelib), GStreamer with `gst-plugins-good`, PyGObject, glibc, and the distribution's audio stack.
- **Windows:** Microsoft Edge WebView2 Runtime, the .NET runtime required by pythonnet, and the Microsoft Visual C++ runtime. If the installer bundles Microsoft's WebView2 Evergreen Bootstrapper, it is an unmodified Microsoft redistributable and is covered by Microsoft's terms, not StemForge's licence.
- **Both:** GPU drivers, if a GPU build is ever offered (v0.1.0 is CPU-only).

If a future packaging change bundles any of these, this notice and the source offer must be reopened.
