What this prototype settled

Decision: variant A, Rail & detail. The signal-path strip and the transport-level Export were folded in from B. A is the default variant; B and C remain below as the exploration record.

Questions on the table

  1. Where do Pitch and Separation live? Beside the track (A), in a persistent actions inspector (B), or as numbered stages (C).
  2. How are multiple renders shown? Proposed: one set of version tabs (Original · +3 · −2) rather than duplicated rows. A/B is a shortcut that flips the tabs.
  3. How does playback work? Proposed: one player at a time across all artifacts; clicking another output takes over. No stem synchronisation.
  4. Where do Jobs live? Global bottom bar (A), inspector activity (B), or inline in the stage that owns them (C). One job at a time either way.
  5. First-run model gate. Proposed: inline blocking card with download size and licence note, not a modal. Download then auto-resubmits Separation once.
  6. How do you Export? Proposed: per-artifact Export where the artifact is listed, plus one Export button for what you're listening to.
  7. Vocals / Instrumental priority. Both primary; drums/bass/other behind a disclosure. Separated but not rendered should show a ghost tile, not an empty rack.
  8. Window chrome. Native OS frame; no close veto; window title StemForge — <Track>; About/attribution is one click from the main surface.

Known prototype controls

Model card has a simulate offline checkbox so the download-failure state is reachable. Everything else is seeded.
